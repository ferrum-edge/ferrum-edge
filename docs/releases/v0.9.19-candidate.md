## Admitted recovery source

[PR #6957](https://github.com/ferrum-edge/ferrum-edge/pull/6957) did three
things:

- provisioned and verified 32 GiB of swap in the protected ARM64 Cross
  producer;
- raised that job's timeout to 240 minutes and refroze its contract;
- prepared 0.9.19.

GPT-6.1 Sol and Muse (xhigh) reported CLEAN on its final head
`d7dd7c114aaa386862d81c23eaaf004096bf5cd8`.
[Qualification run 40430736565](https://github.com/ferrum-edge/ferrum-edge/actions/runs/40430736565)
ran a non-publishing copy of that producer on a hosted `ubuntu-24.04` runner.
The copy omitted only the frozen Cross policy revalidation step; the recovery
record explains why. The swap step activated, and the build step, which
includes the fat-LTO link, completed in 40 minutes 52 seconds. Cargo itself
reported 39 minutes 52 seconds.

PR #6957 changes protected producer and verifier surfaces. Its own head's
`CI Plan`, `CI Policy` and `Trusted Cross Build Policy` checks therefore failed
by design. `Tests` failed because CI planning and complete trusted-policy
verification did not succeed. It was merged through an
administrator ruleset bypass as a squash commit at
`8a35ddf8ff41e594935f599d74fd46d33ea56a70`. That commit cannot itself be a
release commit.

## Production publication evidence

[Release run 40457120201](https://github.com/ferrum-edge/ferrum-edge/actions/runs/40457120201)
completed successfully on the exact tag commit. **All 20 jobs succeeded**,
including release version and SHA validation, every binary and image build,
Linux GNU ABI verification, anonymous image pulls, signing and attestation,
GitHub Release creation, and both final publication gates.

The [ARM64 producer](https://github.com/ferrum-edge/ferrum-edge/actions/runs/40457120201/job/122033261849)
successfully provisioned and verified the **32 GiB** swap file. Its build
step, including dependency compilation and the fat-LTO link, ran from
05:48:19 to 06:24:20 UTC: **36 minutes 1 second**. This is production
evidence for the admitted recovery, following the separate pre-tag
qualification above.

The published release contains all five gateway binaries and both Linux CNI
binaries, each with its checksum file. The default, `-ebpf` and `-ebpf-tools`
image families completed their manifest, signing and attestation jobs; the
image-attestation gate succeeded at 07:06:26 UTC after GitHub Release creation.
