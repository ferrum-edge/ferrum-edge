## Release source

[PR #7016](https://github.com/ferrum-edge/ferrum-edge/pull/7016) prepared
0.9.20: the package, lockfile and chart versions, the changelog section and the
upgrade guide. It changed no protected producer or verifier surface, so its own
merge commit is the release commit. Before its final review round the branch
merged main at `195fe951e2514395ed1c258652eb0e1fce927247`, the squash commit
of [PR #7005](https://github.com/ferrum-edge/ferrum-edge/pull/7005). The release
therefore includes
[PR #7001](https://github.com/ferrum-edge/ferrum-edge/pull/7001)
(`bcb3c56e0`, the DTLS 1.3 `certificate_authorities` fix) and PR #7005.

GPT-6.1 Sol and Muse (xhigh) both approved the final head
`57eebd179c9b5dc7839c507487f9fef61b02fb14`, and every required check passed on
that head. One `Unit Tests (plugins-b)` attempt failed on runner disk
exhaustion (`No space left on device`); only the failed jobs were rerun. PR
#7016 was merged with a **merge commit** at
`e4a606a00352674daaef08636e3e359e6c48ba18`. Its first parent is
`195fe951e2514395ed1c258652eb0e1fce927247`, its second parent is the reviewed
head, and the merge tree equals that head's tree.

## Production publication evidence

[Start Production Release run 41583173140](https://github.com/ferrum-edge/ferrum-edge/actions/runs/41583173140)
ran from `main` at the merge commit. Its validation job waited for every
publish-blocking check on that exact commit, from 05:18:48 to 06:32:49 UTC. It
then created the `v0.9.20` tag (its `Create immutable tag` step completed at
06:32:52 UTC), which triggered the release run at 06:32:54 UTC.

[Release run 41590569525](https://github.com/ferrum-edge/ferrum-edge/actions/runs/41590569525)
completed successfully on the tag commit. **All 20 jobs succeeded**, including:

- release version and SHA validation;
- every binary and image build;
- Linux GNU ABI verification;
- the anonymous image pull smoke;
- signing and attestation;
- GitHub Release creation;
- both final publication gates.

The ARM64 Linux build ran from 06:34:09 to 07:22:21 UTC. The macOS builds
finished last among the binary builds, at 08:38:38 and 08:55:35 UTC. The image-attestation gate
succeeded at 09:01:22 UTC, after GitHub Release creation.

The published release contains all five gateway binaries and both Linux CNI
binaries, each with its checksum file. The default, `-ebpf` and `-ebpf-tools`
image families completed their manifest, signing and attestation jobs.
