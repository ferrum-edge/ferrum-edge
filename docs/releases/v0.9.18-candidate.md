# Ferrum Edge 0.9.18 candidate provenance

This pre-publication record covers the source and the protected merge for the
0.9.18 release. Release changes and rollout requirements are in the
[changelog](../../CHANGELOG.md#0918---2026-10-26) and
[upgrade guide](../upgrade_guide.md#upgrading-to-0918). The previous published
release is v0.9.17.

## Reviewed source and the initial main commit

[PR #6944](https://github.com/ferrum-edge/ferrum-edge/pull/6944) prepared the
release metadata. Cargo's package version and both Helm chart appVersions are
`0.9.18`. Two independent reviewers (GPT-6.1 Sol and Muse, xhigh) reported
CLEAN on its final head `77d578f6d9cff43478a8c234fe53df65f2c8b1bc`, and every
check on that head completed successfully or with a legitimate skip.

It was squash-merged at `dc7009b4c6a94bf554faa9f4c1944eae72e7d43e` on
October 26, 2026 at 09:49:58 UTC. That commit has one parent,
`ba419a00a25914a33bd1c81bc1f02d32effcbbf2`. Its Git tree is identical to the
reviewed head: both trees are `f0f7138226d7de8316edcdd6692cab12724572bd`.

Tree equivalence does not satisfy the protected publication gate. The
[publication-check inventory](../../.github/required-publication-checks.json)
binds evidence to the producing PR's head through the release commit's second
parent, and [`resolve_pr_head`](../../.github/scripts/verify_publication_gate.py)
refused the one-parent commit in
[Start Production Release run 40302638790](https://github.com/ferrum-edge/ferrum-edge/actions/runs/40302638790)
with:

```text
dc7009b4c6a94bf554faa9f4c1944eae72e7d43e has no second parent and cannot be bound to a PR head
```

No tag was created by that run.

## Protected merge

This record is the protected follow-up, as for 0.9.16. Its PR is cut from main
at `dc7009b4c6a94bf554faa9f4c1944eae72e7d43e` and merged with a **merge
commit**, so its reviewed head is the second parent and the merge tree equals
that head's tree. **Start Production Release** then runs for `v0.9.18` from that
merge commit. A post-publication record replaces this candidate record once the
release, its images, and the matching `contracts-edge-0.9.18` tag are verified.
