- **Unreleased changelog entries move to `changelog.d/` fragments** (issue
  #4487). Each pull request with a user-visible change now adds one small
  `changelog.d/<ref>.<section>.md` file instead of appending to the shared
  `## [Unreleased]` block in `CHANGELOG.md`, and breaking changes add a matching
  `<ref>.upgrade.md` instead of appending to `docs/upgrade_guide.md`. Two pull
  requests touching no common source file no longer conflict in the changelog.
  `scripts/assemble_changelog.py` previews, validates, and — at release time —
  assembles the fragments into a released section; the `Unit Tests` job enforces
  the fragment rules. This changes the contributor workflow only; released
  changelog and upgrade-guide output is unchanged.
