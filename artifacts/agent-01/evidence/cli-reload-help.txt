Send a reload signal (SIGHUP) to a running gateway instance

Usage: ferrum-edge reload [OPTIONS]

Options:
  -p, --pid <PID>
          PID of the running gateway (auto-detected if omitted).
          
          Must be a positive process ID. `0` is rejected because POSIX `kill` treats it as this process group. This CLI process is also rejected.

  -h, --help
          Print help (see a summary with '-h')
